# SHOPAGG CMS 后台使用指南

> **归属仓库**：`shopagg-b2b-website`
> **适用范围**：站点管理员、运营、内容编辑与销售跟单人员；公开在线手册同步见 `https://shopagg.org/usage`。
> **相关文档**：[系统架构](architecture.md) · [模板开发指南](theme-development.md)

---

## 1. 首次登录与初始化

后台入口为 `/admin/login`。首次登录后务必按顺序完成四项基础初始化：

1. **修改默认管理员密码**（右上角头像菜单 → 个人资料）。
2. **完善基础信息**（系统设置 → 基础设置）：填写网站名称、标语、Logo、Favicon、默认 SEO 标题与描述。
3. **补全联系方式**（系统设置 → 联系方式）：配置企业邮箱、电话、地址、WhatsApp 与社媒链接。
4. **确认外观主题**（外观区块 → 网站模版）：确认目标主题已启用并检查首屏轮播与导航菜单。

## 2. 后台功能导航与角色分工

| 模块 | 核心功能 | 建议授权角色 |
| --- | --- | --- |
| **仪表盘** | 查看产品、内容、留言、待处理询盘与近期互动概览 | 全部登录人员 |
| **收件箱** | 处理联系留言与产品询盘，支持状态流转与 CSV 导出 | 管理员、销售跟单 |

## 3. 核心业务操作

### 3.1 产品中心

进入 **产品中心 → 产品列表** 新增或编辑产品：

- **基础字段**：标题、摘要、富文本详情、产品图集、分类、标签、供应商、产品类型与独立 SEO 字段。
- **价格与规格**：支持无价格/询盘价、固定单价、区间价、阶梯价以及多规格 SKU 配置。
- **URL 别名（Slug）规则**：全站所有产品、文章、页面与菜单的 Slug 仅允许**小写字母、数字和连字符 `-`**，留空时自动生成，建议使用清晰英文短语（如 `stainless-steel-pipe`）。
- **分类结构**：建议先建一级行业/品类目录，再建立子分类，避免未分类产品影响前台筛选。

### 3.2 内容与媒体库

- **文章（`/blog/:slug`）**：用于公司新闻、行业资讯、采购指南与展会动态。
- **案例（`/case/:slug`）**：用于展示出口项目、定制交付案例，建议统一配置封面图。
- **独立页（`/page/:slug`）**：用于关于我们、服务介绍、FAQ、合作政策等固定页面。
- **媒体库**：支持图片（≤ 10 MB）与视频（≤ 50 MB）上传、文件夹分类（建议按 `products` / `banners` / `certificates` / `company` / `blog` 组织）、搜索与跨页面复用。

### 3.3 收件箱与询盘跟进

- **联系留言**：承接前台联系表单，支持查看与清理无效垃圾留言。
- **产品询盘**：自动记录客户姓名、公司、联系方式、关联产品、采购数量、来源 URL 与 IP。
- 推荐按状态流转跟进：`待处理` → `已联系` → `已报价` → `已关闭`，需要导入外部 CRM 时点击 **导出 CSV**。

### 3.4 外观区块（主题、区块、菜单、轮播）

- **网站模版**：支持查看已安装主题（读取 `screenshot.jpg` 封面）、上传符合规范的 ZIP 主题包及切换启用；应用商店来源的主题支持版本检查与授权状态显示。
- **模板区块**：按所属页面（首页、关于页、联系页、全站通用、品牌颜色）可视化修改文案、图片、媒体、选品与开关，修改后点击 **保存全部区块**；改乱时可勾选重置为模板默认值。
- **菜单管理**：支持多菜单、多级嵌套与拖拽排序，常用标识为 `main-nav`（顶部主导航）和 `footer`（页脚链接）。
- **轮播图**：集中维护多组轮播图（图片、标题、副标题、按钮与链接），供主题区块下拉选择；建议同组图片尺寸保持一致。

### 3.5 系统设置与程序更新

- 上线前重点核对 **基础设置**、**公司简介**、**联系方式** 三个标签页。
- **翻译设置**：控制前台在线翻译组件的启用状态与语言列表。
- **自定义代码**：支持注入站长验证标签或第三方脚本（托管版获客统计与客服脚本由平台 `shopagg-growth` 插件自动管理，无需手工粘贴重复脚本）。
- **程序更新**：支持在线检查 GitHub Release 新版本、备份并安装更新、查看迁移与更新日志。

## 4. 常见问题排查

| 现象 | 排查要点 |
| --- | --- |
| 上传 ZIP 主题包提示不符合要求 | 确认压缩包内仅包含单套主题目录、根目录有 `style.css` 且含 `Theme Name` 头部注释、必需模板文件完整 |
| 主题列表显示“无预览图片” | 在主题根目录补充 `screenshot.jpg` 后刷新页面 |
| 模板区块保存后前台未更新 | 核对当前启用主题是否与编辑的主题一致、是否点击“保存全部区块”、是否误勾选了“重置为默认值” |
| 员工登录后看不到外观或设置菜单 | 普通员工（`staff`）仅展示已勾选模块，外观区块与员工管理默认仅管理员可见 |
