# 主题更新说明

本次按 [SHOPAGG CMS 主题开发规范](https://shopagg.org/developer/themes)（适用版本 1.3.4，规则更新于 2026-10-12）进行兼容更新。

## 后台维护

- 在「应用商店 → 网站主题」启用本主题。
- 在「外观区块 → 模板区块」编辑首页、品牌、页头、页脚、页面标题、按钮、表单提示与空状态文案；页面的固定界面文字集中在对应的「界面文案」区块。
- 通过产品选择器配置推荐产品和相关产品。显示数量字段设有上下限；产品价格、图片与链接继续来自真实产品。
- 首屏轮播图片、文字和按钮在「外观区块 → 轮播图」维护。支持轮播的主题只在模板区块选择轮播 Slug；静态首屏主题保留原有设计。
- 在首页视频区块通过媒体库选择视频和封面；未设置视频时展示封面或预约参观提示，不输出无效播放器。
- 公司资料、联系人、社交账号、工厂相册与资质证书仍由系统设置统一维护。
- 已有区块标识与自定义值保留；更新主题不会重写 storage/blocks/ 中的运营配置。

## 打包与维护

打包时必须同时包含 blocks.php、block-settings.php、functions.php、theme-support.php、theme-support.css，以及全部页面模板和本地资源。主题辅助函数已放在自身目录，可独立安装，不依赖默认主题的 functions.php。

已补齐独立页面、搜索页面及插件页面入口，并检查元数据、安全输出、媒体路径与子目录链接。富文本正文继续使用系统 process_rich_text() 处理。

主程序仓库提供 `php tests/theme_render_smoke.php`，覆盖 5 套主题的独立渲染、根目录与子目录、价格模式、后台文案覆盖、区块隐藏、视频选择、动态文本转义与结构化数据。

本次更新不改变本主题原有版权或授权条款。
